# Referência sanitizada do Nushell

Estes arquivos foram derivados do ZIP fornecido apenas para comparação de comportamento durante a reescrita.

**Não editar durante a implementação e não usar como destino do código Go.**

A referência foi sanitizada quando havia nomes/paths/contexto pessoal desnecessário. Por isso os checksums deste diretório comprovam a integridade **deste pacote de referência**, não identidade byte-a-byte com o ZIP original.

Foram mantidos somente fontes/documentos necessários às duas CLIs. Decisões históricas sensíveis foram consolidadas em `../current-state-audit.md`, `../ai-profile-parity.md` e `nushell/ai_profiles/decision-summary.md`.
